# Audra v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A macOS menu bar app that reads aloud the text selected in any application, offline, triggered by a global hotkey or the menu.

**Architecture:** A Swift Package with two targets. `AudraCore` (library) holds all logic behind small protocols so it can be unit-tested with fakes: speed mapping, voice selection, language detection, settings persistence, a speech state machine, selected-text capture (Accessibility API with a clipboard ⌘C fallback), and a coordinator that ties them together. `AudraApp` (executable) is a thin SwiftUI layer: `MenuBarExtra`, a `Settings` scene, global hotkey wiring, and permission handling. Shell scripts turn the SwiftPM binary into an ad-hoc-signed `.app` and a `.dmg`.

**Tech Stack:** Swift (tools 5.10, Swift 5 language mode), SwiftUI, AppKit, AVFoundation (`AVSpeechSynthesizer`), NaturalLanguage, ApplicationServices (AX API), CoreGraphics (`CGEvent`), XCTest, [KeyboardShortcuts](https://github.com/sindresorhus/KeyboardShortcuts) 2.x.

**Spec:** `docs/superpowers/specs/2026-10-01-audra-design.md` (requirements source: `README.md`)

```swift
import AVFoundation

/// Playback speeds offered to the user. The raw value is the multiplier shown in the UI.
public enum SpeechSpeed: Double, CaseIterable, Identifiable, Codable {
    case half = 0.5
    case normal = 1.0
    case oneAndHalf = 1.5
    case double = 2.0
    case twoAndHalf = 2.5

    public var id: Double { rawValue }

    /// Menu label, e.g. "1x" or "1.5x".
    public var label: String {
        let isWhole = rawValue.truncatingRemainder(dividingBy: 1) == 0
        return (isWhole ? String(Int(rawValue)) : String(rawValue)) + "x"
    }

    /// Value for `AVSpeechUtterance.rate`. AVSpeech rates are perceptually non-linear
    /// (0.5 is normal speech, 1.0 is extremely fast), so this is a table tuned by ear
    /// rather than a multiplication.
    public var utteranceRate: Float {
        switch self {
        case .half: return 0.40
        case .normal: return AVSpeechUtteranceDefaultSpeechRate
        case .oneAndHalf: return 0.57
        case .double: return 0.63
        case .twoAndHalf: return 0.69
        }
    }
}
```

```swift
import Foundation

/// An installed speech voice, decoupled from AVFoundation so selection logic is testable.
public struct VoiceInfo: Identifiable, Hashable {
    public enum Quality: Int, Comparable {
        case standard = 1
        case enhanced = 2
        case premium = 3

        public static func < (lhs: Quality, rhs: Quality) -> Bool { lhs.rawValue < rhs.rawValue }
    }

    /// `AVSpeechSynthesisVoice.identifier`.
    public let id: String
    public let name: String
    /// BCP-47 tag, e.g. "en-US".
    public let language: String
    public let quality: Quality

    public init(id: String, name: String, language: String, quality: Quality) {
        self.id = id
        self.name = name
        self.language = language
        self.quality = quality
    }

    /// Primary language subtag, e.g. "en" for "en-US".
    public var languageCode: String { Self.primaryLanguage(of: language) }

    public static func primaryLanguage(of tag: String) -> String {
        let primary = tag.split(whereSeparator: { $0 == "-" || $0 == "_" }).first.map(String.init) ?? tag
        return primary.lowercased()
    }
}
```

`Sources/AudraCore/Voices/VoiceSelector.swift`:
```swift
import Foundation

public enum VoiceSelector {
    /// Picks the voice for a piece of text. Order of preference:
    /// 1. the user's override for the detected language,
    /// 2. the default voice, if it speaks the detected language,
    /// 3. the best-quality installed voice for the detected language (ties: name A–Z),
    /// 4. the default voice.
    /// Returns nil to let the system use its own default voice.
    public static func selectVoice(
        detectedLanguage: String?,
        defaultVoiceID: String?,
        languageOverrides: [String: String],
        availableVoices: [VoiceInfo]
    ) -> String? {
        let voicesByID = Dictionary(availableVoices.map { ($0.id, $0) }, uniquingKeysWith: { first, _ in first })
        let defaultVoice = defaultVoiceID.flatMap { voicesByID[$0] }

        guard let detectedLanguage else { return defaultVoice?.id }
        let code = VoiceInfo.primaryLanguage(of: detectedLanguage)

        if let overrideID = languageOverrides[code], voicesByID[overrideID] != nil {
            return overrideID
        }
        if let defaultVoice, defaultVoice.languageCode == code {
            return defaultVoice.id
        }
        let best = availableVoices
            .filter { $0.languageCode == code }
            .max { lhs, rhs in
                lhs.quality != rhs.quality ? lhs.quality < rhs.quality : lhs.name > rhs.name
            }
        return best?.id ?? defaultVoice?.id
    }
}
```

```swift
public enum SystemVoices {
    /// Installed voices, excluding novelty voices, sorted by language then name.
    public static func all() -> [VoiceInfo] {
        AVSpeechSynthesisVoice.speechVoices()
            .filter { !$0.voiceTraits.contains(.isNoveltyVoice) }
            .map {

    }
```

```swift
import NaturalLanguage

public protocol LanguageDetecting {
    /// BCP-47 language code of `text` (e.g. "en", "pt", "zh-Hans"), or nil when unsure.
    func detectLanguage(of text: String) -> String?
}

/// On-device language detection; never touches the network.
public struct NLLanguageDetector: LanguageDetecting {
    private let minimumConfidence: Double

    public init(minimumConfidence: Double = 0.5) {
        self.minimumConfidence = minimumConfidence
    }

    public func detectLanguage(of text: String) -> String? {
        guard !text.trimmingCharacters(in: .whitespacesAndNewlines).isEmpty else { return nil }
        let recognizer = NLLanguageRecognizer()
        recognizer.processString(text)
        guard let top = recognizer.languageHypotheses(withMaximum: 1).max(by: { $0.value < $1.value }),
              top.value >= minimumConfidence else { return nil }
        return top.key.rawValue
    }
}
```

```swift
import Combine
import Foundation

/// User preferences, persisted to UserDefaults on every change.
@MainActor
public final class SettingsStore: ObservableObject {
    private enum Key {
        static let speed = "speechSpeed"
        static let defaultVoiceID = "defaultVoiceID"
        static let autoDetectLanguage = "autoDetectLanguage"
        static let languageVoiceOverrides = "languageVoiceOverrides"
    }

    private let defaults: UserDefaults

    @Published public var speed: SpeechSpeed {
        didSet { defaults.set(speed.rawValue, forKey: Key.speed) }
    }

    /// Voice used when no language-specific voice applies. nil = system default.
    @Published public var defaultVoiceID: String? {
        didSet { defaults.set(defaultVoiceID, forKey: Key.defaultVoiceID) }
    }

    @Published public var autoDetectLanguage: Bool {
        didSet { defaults.set(autoDetectLanguage, forKey: Key.autoDetectLanguage) }
    }

    /// Primary language code ("en", "pt", …) → voice identifier.
    @Published public private(set) var languageVoiceOverrides: [String: String] {
        didSet { defaults.set(languageVoiceOverrides, forKey: Key.languageVoiceOverrides) }
    }

    public init(defaults: UserDefaults = .standard) {
        self.defaults = defaults
        speed = SpeechSpeed(rawValue: defaults.double(forKey: Key.speed)) ?? .normal
        defaultVoiceID = defaults.string(forKey: Key.defaultVoiceID)
        autoDetectLanguage = defaults.object(forKey: Key.autoDetectLanguage) as? Bool ?? true
        languageVoiceOverrides = defaults.dictionary(forKey: Key.languageVoiceOverrides) as? [String: String] ?? [:]
    }
```

```swift
import Combine
import Foundation

/// Tracks playback state on top of a `SpeechSynthesizing` engine.
@MainActor
public final class SpeechController: ObservableObject {
    public enum State: Equatable {
        case idle
        case speaking
        case paused
    }

    @Published public private(set) var state: State = .idle
    private let synthesizer: any SpeechSynthesizing

    public init(synthesizer: any SpeechSynthesizing) {
        self.synthesizer = synthesizer
        synthesizer.onFinish = { [weak self] in
            self?.state = .idle
        }
    }

    /// Speaks `text`, replacing anything currently playing.
    public func speak(_ text: String, voiceID: String?, rate: Float) {
        if state != .idle { synthesizer.stop() }
        synthesizer.speak(text, voiceID: voiceID, rate: rate)
        state = .speaking
    }

    public func stop() {
        guard state != .idle else { return }
        synthesizer.stop()
        state = .idle
    }

    public func pause() {
        guard state == .speaking else { return }
        synthesizer.pause()
        state = .paused
    }

    public func resume() {
        guard state == .paused else { return }
        synthesizer.resume()
        state = .speaking
    }

    public func togglePause() {
        state == .paused ? resume() : pause()
    }
}
```

```swift
import AVFoundation

/// `SpeechSynthesizing` backed by the offline system speech engine.
@MainActor
public final class AVSpeechSynthesizerAdapter: NSObject, SpeechSynthesizing {
    public var onFinish: (@MainActor () -> Void)?
    private let synthesizer = AVSpeechSynthesizer()
    private var currentUtterance: AVSpeechUtterance?

    public override init() {
        super.init()
        synthesizer.delegate = self
    }

    public func speak(_ text: String, voiceID: String?, rate: Float) {
        let utterance = AVSpeechUtterance(string: text)
        if let voiceID, let voice = AVSpeechSynthesisVoice(identifier: voiceID) {
            utterance.voice = voice
        }
        utterance.rate = rate
        currentUtterance = utterance
        synthesizer.speak(utterance)
    }

    public func stop() {
        currentUtterance = nil
        synthesizer.stopSpeaking(at: .immediate)
    }

    public func pause() {
        synthesizer.pauseSpeaking(at: .word)
    }

    public func resume() {
        synthesizer.continueSpeaking()
    }
}

extension AVSpeechSynthesizerAdapter: AVSpeechSynthesizerDelegate {
    nonisolated public func speechSynthesizer(_ synthesizer: AVSpeechSynthesizer, didFinish utterance: AVSpeechUtterance) {
        let finished = ObjectIdentifier(utterance)
        Task { @MainActor in
            guard let current = self.currentUtterance, ObjectIdentifier(current) == finished else { return }
            self.currentUtterance = nil
            self.onFinish?()
        }
    }
}
```

```swift
/// `PasteboardAccessing` backed by a real `NSPasteboard` (the general clipboard by default).
@MainActor
public final class SystemPasteboard: PasteboardAccessing {
    private let pasteboard: NSPasteboard

    public init(pasteboard: NSPasteboard = .general) {
        self.pasteboard = pasteboard
    }

    public var changeCount: Int { pasteboard.changeCount }

    public func snapshot() -> PasteboardSnapshot {
        let items = (pasteboard.pasteboardItems ?? []).map { item in
            Dictionary(
                item.types.compactMap { type in item.data(forType: type).map { (type.rawValue, $0) } },
                uniquingKeysWith: { first, _ in first }
            )
        }
        return PasteboardSnapshot(items: items)
    }

    public func restore(_ snapshot: PasteboardSnapshot) {
        pasteboard.clearContents()
        let items = snapshot.items.map { entries -> NSPasteboardItem in
            let item = NSPasteboardItem()
            for (type, data) in entries {
                item.setData(data, forType: NSPasteboard.PasteboardType(type))
            }
            return item
        }
        if !items.isEmpty {
            pasteboard.writeObjects(items)
        }
    }

    public func readString() -> String? {
        pasteboard.string(forType: .string)
    }
}
```

```swift

/// Fallback for apps that don't expose their selection to the Accessibility API:
/// press ⌘C, read the clipboard, then put the user's clipboard back.
@MainActor
public final class ClipboardTextSource: SelectedTextSource {
    private let pasteboard: any PasteboardAccessing
    private let copySender: any CopyCommandSending
    private let timeout: Duration
    private let pollInterval: Duration

    public init(
        pasteboard: any PasteboardAccessing,
        copySender: any CopyCommandSending,
        timeout: Duration = .milliseconds(300),
        pollInterval: Duration = .milliseconds(10)
    ) {
        self.pasteboard = pasteboard
        self.copySender = copySender
        self.timeout = timeout
        self.pollInterval = pollInterval
    }

    public func selectedText() async -> String? {
        let saved = pasteboard.snapshot()
        let initialChangeCount = pasteboard.changeCount
        copySender.sendCopyCommand()

        let clock = ContinuousClock()
        let deadline = clock.now.advanced(by: timeout)
        while pasteboard.changeCount == initialChangeCount, clock.now < deadline {
            try? await Task.sleep(for: pollInterval)
        }
        // Nothing was copied (no selection, or the app ignored ⌘C): the clipboard is untouched.
        guard pasteboard.changeCount != initialChangeCount else { return nil }

        let text = pasteboard.readString()
        pasteboard.restore(saved)
        return text
    }
}
```

`Sources/AudraCore/ReadSelectionCoordinator.swift`:
```swift
import Foundation

/// Glue between the hotkey/menu and the speech engine:
/// capture selection → detect language → choose voice → speak.
@MainActor
public final class ReadSelectionCoordinator {
    private let textSource: any SelectedTextSource
    private let speech: SpeechController
    private let settings: SettingsStore
    private let languageDetector: any LanguageDetecting
    private let availableVoices: () -> [VoiceInfo]
    private let onNoText: () -> Void
    private var isCapturing = false

    public init(
        textSource: any SelectedTextSource,
        speech: SpeechController,
        settings: SettingsStore,
        languageDetector: any LanguageDetecting,
        availableVoices: @escaping () -> [VoiceInfo],
        onNoText: @escaping () -> Void
    ) {
        self.textSource = textSource
        self.speech = speech
        self.settings = settings
        self.languageDetector = languageDetector
        self.availableVoices = availableVoices
        self.onNoText = onNoText
    }

    /// Hotkey behaviour: stop if anything is playing or paused, otherwise read the selection.
    public func toggle() async {
        if speech.state != .idle {
            speech.stop()
            return
        }
        await readSelection()
    }

    /// Reads the current selection aloud, replacing any speech in progress.
    public func readSelection() async {
        // Ignore repeated presses while a capture (up to ~300 ms with the clipboard fallback) is running.
        guard !isCapturing else { return }
        isCapturing = true
        defer { isCapturing = false }

        let text = (await textSource.selectedText() ?? "").trimmingCharacters(in: .whitespacesAndNewlines)
        guard !text.isEmpty else {
            onNoText()
            return
        }

        let language = settings.autoDetectLanguage ? languageDetector.detectLanguage(of: text) : nil
        let voiceID = VoiceSelector.selectVoice(
            detectedLanguage: language,
            defaultVoiceID: settings.defaultVoiceID,
            languageOverrides: settings.languageVoiceOverrides,
            availableVoices: availableVoices()
        )
        speech.speak(text, voiceID: voiceID, rate: settings.speed.utteranceRate)
    }
}
```

```swift
/// Reading other apps' selections and sending ⌘C both require the Accessibility permission.
enum AccessibilityPermission {
    static var isGranted: Bool { AXIsProcessTrusted() }

    /// Shows the system "would like to control this computer" prompt if not yet granted.
    static func request() {
        let options = [kAXTrustedCheckOptionPrompt.takeUnretainedValue() as String: true] as CFDictionary
        _ = AXIsProcessTrustedWithOptions(options)
    }

    static func openSystemSettings() {
        let url = URL(string: "x-apple.systempreferences:com.apple.preference.security?Privacy_Accessibility")!
```

```swift
import AppKit
import KeyboardShortcuts
import AudraCore

@MainActor
final class AppModel: ObservableObject {
    let settings: SettingsStore
    let speech: SpeechController
    @Published private(set) var hasAccessibilityPermission = AccessibilityPermission.isGranted

    private let coordinator: ReadSelectionCoordinator
    private var permissionTimer: Timer?

    init() {
        let settings = SettingsStore()
        let speech = SpeechController(synthesizer: AVSpeechSynthesizerAdapter())
        let textSource = FirstAvailableTextSource([
            AccessibilityTextSource(),
            ClipboardTextSource(pasteboard: SystemPasteboard(), copySender: CopyKeySender()),
        ])
        self.settings = settings
        self.speech = speech
        coordinator = ReadSelectionCoordinator(
            textSource: textSource,
            speech: speech,
            settings: settings,
            languageDetector: NLLanguageDetector(),
            availableVoices: { SystemVoices.all() },
            onNoText: { NSSound.beep() }
        )

        KeyboardShortcuts.onKeyUp(for: .readSelection) { [weak self] in
            Task { @MainActor in await self?.toggleReading() }
        }

        if !hasAccessibilityPermission {
            AccessibilityPermission.request()
            pollForPermission()
        }
    }

    /// Hotkey action: stop if speaking or paused, otherwise read the selection.
    func toggleReading() async {
        if speech.state == .idle && !ensurePermission() { return }
        await coordinator.toggle()
    }

    /// "Read Selection" menu action.
    func readSelection() async {
        guard ensurePermission() else { return }
        await coordinator.readSelection()
    }

    private func ensurePermission() -> Bool {
        hasAccessibilityPermission = AccessibilityPermission.isGranted
        if !hasAccessibilityPermission {
            AccessibilityPermission.request()
            pollForPermission()
        }
        return hasAccessibilityPermission
    }

    /// The grant happens in System Settings while we run, so poll until it shows up.
    private func pollForPermission() {
        guard permissionTimer == nil else { return }
        permissionTimer = Timer.scheduledTimer(withTimeInterval: 2, repeats: true) { [weak self] timer in
            MainActor.assumeIsolated {
                guard let self else { return timer.invalidate() }
                self.hasAccessibilityPermission = AccessibilityPermission.isGranted
                if self.hasAccessibilityPermission {
                    timer.invalidate()
                    self.permissionTimer = nil
                }
            }
        }
    }
}
```

```swift
import Foundation

/// Installed voices for one language, for the per-language voice settings.
public struct LanguageVoiceGroup: Identifiable, Equatable {
    public let languageCode: String
    public let displayName: String
    public let voices: [VoiceInfo]

    public var id: String { languageCode }

    public static func groups(from voices: [VoiceInfo], locale: Locale = .current) -> [LanguageVoiceGroup] {
        Dictionary(grouping: voices, by: \.languageCode)
            .map { code, voices in
                LanguageVoiceGroup(
                    languageCode: code,
                    displayName: locale.localizedString(forLanguageCode: code) ?? code,
                    voices: voices.sorted { ($0.name, $0.language) < ($1.name, $1.language) }
                )
            }
            .sorted { $0.displayName.localizedCaseInsensitiveCompare($1.displayName) == .orderedAscending }
    }
}
```

```bash
#!/usr/bin/env bash
# Builds the app and packages it as build/Audra-<version>.dmg with an Applications shortcut.
set -euo pipefail
cd "$(dirname "$0")/.."

VERSION="$(/usr/libexec/PlistBuddy -c "Print CFBundleShortVersionString" Support/Info.plist)"
STAGING="build/dmg"
DMG="build/Audra-$VERSION.dmg"
```

````markdown
# Audra

A small macOS menu bar app that reads aloud the text you select in any application — fully offline.

## Features

- Reads aloud selected text from any app that allows text selection.
- Global hotkey (default **⌥⇧S**, configurable): press to read, press again to stop.
- Menu bar controls: Read Selection, Pause/Resume, Stop, Speed.
- Speeds: 0.5x, 1x, 1.5x, 2x, 2.5x.
- Detects the language of the text and picks a matching voice; per-language voice overrides.
- Uses the voices installed on your Mac. No internet connection needed.
- Never stores or transmits the text it reads.

## Requirements

- macOS 14 Sonoma or later
- To build: Xcode (Swift 6 toolchain)

## Install

1. Download `Audra-<version>.dmg`, open it, drag **Audra** to Applications.
2. The app is not notarized yet, so the first time: right-click the app → **Open** → **Open**.
3. Grant **Accessibility** access when asked (System Settings → Privacy & Security → Accessibility). It is needed to read other apps' selections.

## Usage

Select text anywhere and press **⌥⇧S**. Press it again to stop. Change the shortcut, speed and voices from the menu bar icon → **Settings…**.

More voices (including Enhanced/Premium quality) can be downloaded in System Settings → Accessibility → Spoken Content → System Voice → Manage Voices.

### How selected text is captured

The app first asks the Accessibility API for the selection. Some apps (e.g. Chrome, Electron apps) don't expose it; for those the app presses ⌘C, reads the clipboard, and immediately restores your previous clipboard contents. Clipboard-history tools may still record that copy.
````
