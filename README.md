# Screen Reader

A simple desktop application that reads aloud the text user selects with their mouse or keyboard.

The first version supports reading aloud selected text from any application without requiring an internet connection.

It is a downloadable desktop MacOS application. But in the future it may be expanded to support other platforms as well like Windows and Linux.

## Features

- Reads aloud selected text from any application.
- Supports multiple languages.
- Customizable voice settings.
- Customizable speed settings (0.5x, 1x, 1.5x, 2x, 2.5x).
- It doesn't require an internet connection to function.
- It doesn't store or transmit the text it reads.
- It works for any app that allows text selection.
